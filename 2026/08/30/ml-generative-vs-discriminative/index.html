Generative Model VS Discriminative Model

1. Generative Model

1.1 核心

学习：

P(x∣y)P(x\mid y) P(x∣y)

通过 Bayes：

P(y∣x)∝P(x∣y)P(y)P(y\mid x)\propto P(x\mid y)P(y) P(y∣x)∝P(x∣y)P(y)

1.2 Example：Gaussian Model

假设：

x∣y∼N(μ,Σ)x|y\sim N(\mu,\Sigma) x∣y∼N(μ,Σ)

概率密度函数：

P(x∣y)=1(2π)d/2∣Σ∣1/2e−12(x−μ)TΣ−1(x−μ)P(x\mid y)= \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} e^{-\frac12(x-\mu)^T\Sigma^{-1}(x-\mu)} P(x∣y)=(2π)d/2∣Σ∣1/21​e−21​(x−μ)TΣ−1(x−μ)

其中：

  • μ\muμ：均值
  • Σ\SigmaΣ：协方差矩阵
  • ddd：特征维度

1.3 Parameter Estimation

Maximum Likelihood

max⁡Likelihood\max Likelihood maxLikelihood

↓

Log Likelihood

max⁡log⁡Likelihood\max \log Likelihood maxlogLikelihood

↓

Negative Log Likelihood

Loss=−log⁡LikelihoodLoss=-\log Likelihood Loss=−logLikelihood

1.4 优点

  • 建模数据分布
  • 可利用先验概率
  • 分布假设合理时有效

1.5 缺点

  • 对分布假设敏感
  • 高维完整分布建模参数多

2. Discriminative Model

2.1 核心

直接学习：

P(y∣x)P(y\mid x) P(y∣x)

2.2 Example：Logistic Regression

Linear：

z=wTx+bz=w^Tx+b z=wTx+b

Sigmoid：

p=σ(z)=11+e−zp=\sigma(z)=\frac{1}{1+e^{-z}} p=σ(z)=1+e−z1​

因此：

p=P(y=1∣x)p=P(y=1\mid x) p=P(y=1∣x)

2.3 Loss：Binary Cross Entropy

L=−[ylog⁡p+(1−y)log⁡(1−p)]L= -\left[ y\log p+(1-y)\log(1-p) \right] L=−[ylogp+(1−y)log(1−p)]

对于二分类 Logistic Regression：

BCE=Negative Log Likelihood\boxed{BCE=Negative\ Log\ Likelihood} BCE=Negative Log Likelihood​

2.4 优点

  • 直接学习 P(y∣x)P(y\mid x)P(y∣x)
  • 不需要强分布假设
  • 关注分类边界

2.5 缺点

  • 无法描述完整数据分布
  • 简单模型表达能力有限
  • 模型复杂度过高容易 Overfitting

3. Maximum Likelihood 与 BCE

Generative Model

Likelihood→Log Likelihood→Negative Log LikelihoodLikelihood \rightarrow Log\ Likelihood \rightarrow Negative\ Log\ Likelihood Likelihood→Log Likelihood→Negative Log Likelihood

Logistic Regression

P(y∣x)→Log Likelihood→Negative Log LikelihoodP(y\mid x) \rightarrow Log\ Likelihood \rightarrow Negative\ Log\ Likelihood P(y∣x)→Log Likelihood→Negative Log Likelihood

二分类 Logistic Regression：

BCE=NLL\boxed{BCE=NLL} BCE=NLL​

4. 总体对比

对比项 Generative Model Discriminative Model
核心 学习数据分布 学习分类关系
学习对象 P(x∣y)P(x\mid y)P(x∣y) P(y∣x)P(y\mid x)P(y∣x)
关注 数据如何产生 如何区分类别
数据分布 需要建模 通常不需要
Classification 间接 直接
Bayes 使用 不需要
代表模型 Gaussian Model Logistic Regression
参数示例 μ,Σ\mu,\Sigmaμ,Σ w,bw,bw,b
参数估计 Maximum Likelihood Maximum Likelihood
Loss Negative Log Likelihood Binary Cross Entropy
优点 建模数据分布；可利用先验；分布假设合理时有效 直接分类；不需要强分布假设；关注分类边界
缺点 分布假设敏感；高维完整分布参数多 简单模型表达能力有限；模型复杂度过高容易 Overfitting
